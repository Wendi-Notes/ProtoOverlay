ProtoOverlay preview assets

This archive contains the ProtoOverlay app icon and four screenshots captured
from the Android Studio emulator running app version 0.2.

The connection-settings screenshot uses the example hostname
https://pc.example.ts.net. It does not contain the private PC/Tailscale
hostname from the connected development environment.

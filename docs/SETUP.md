# 利用者向けセットアップガイド

## 必要なもの

- Android 11（API 30）以降のスマートフォン
- Windows、macOS、または Linux の PC
- PC 上で動作する ProtoOverlay 対応エージェントと LiveKit サーバー
- PC とスマートフォンを同じプライベートネットワークに接続する方法（Tailscale を使う場合は両方にインストールし、同じ tailnet に参加）

**APK だけでは音声 AI は動作しません。** PC 側エージェントや LiveKit の構築はこのリポジトリに含まれず、別途準備が必要です。

## 1. PC・ネットワークを準備する

1. PC 側エージェントが起動し、`/token?character=proto` の HTTP エンドポイントを提供していることを確認します。
2. エンドポイントは JSON で `url` と `token` を返す必要があります。`url` はエージェントが参加する LiveKit サーバーを指し、`token` は短期間・必要最小限の権限に制限してください。
3. Tailscale を使う場合は PC とスマートフォンの両方を同じ tailnet に参加させ、スマートフォンから PC のサービスにアクセスできるようにします。
4. Android に入力する PC 側 URL は、トークンエンドポイントまで含めず、例として `https://pc-name.example.ts.net` のようなベース URL にします。アプリが末尾に `/token?character=proto` を付けます。

HTTPS の利用を推奨します。LiveKit の WebSocket／メディア通信が tailnet 上で使えるかはサーバー構成、DNS、ファイアウォール、UDP、TURN に依存します。ネットワークの設定や外部公開が必要な場合は、PC・LiveKit の管理者と確認してください。

### 音声処理の選択肢

LiveKit は主にリアルタイムの音声・映像・データ通信を担います。音声認識（STT）や音声合成（TTS）には、LiveKit Agents と外部サービスを組み合わせる方法や、PC 側エージェントの実装に応じてプロバイダーを切り替える方法があります。PC 上のローカル／自前の STT・LLM・TTS で処理する構成も可能です。料金は選ぶサービスや契約によって異なります。いずれも PC 側エージェントでの実装・設定が必要で、Android アプリから方式を選ぶことはできません。

## 2. Android に APK を入れる

1. [GitHub Releases](https://github.com/Wendi-Notes/ProtoOverlay/releases) から APK をダウンロードします。リリースがない場合は、まだ配布用 APK が公開されていません。
2. ダウンロードした APK をタップします。Android の案内が出た場合は、使用したブラウザーまたはファイル管理アプリに限って「不明なアプリのインストール」を許可します。
3. インストール後にアプリを開きます。署名が検証できない APK や、信頼できない場所から取得した APK はインストールしないでください。

Android 11 以降が必要です。Android のバージョンや端末メーカーにより、設定画面の名前は異なる場合があります。

## 3. 権限と接続先を設定する

1. アプリで「他のアプリの上に重ねて表示」を許可します。常駐サービスを開始するとマスコットが表示されます。
2. PC 側のベース URL を入力して保存します。URL は `/token?character=proto` より前の部分です。
3. 音声通話にはマイクと通知の権限が必要です。カメラ送信を使う場合だけカメラを許可してください。
4. プロトを起動し、ダッシュボードの接続状態を確認します。

カメラ映像または画面共有を PC に送る操作をすると、Android の確認ダイアログが表示されることがあります。内容を確認してから許可してください。

## よくある問題

| 状態 | 確認すること |
|---|---|
| 接続 URL が未設定 | PC 側のベース URL を入力したか。末尾に `/token` は付けない |
| トークン取得に失敗 | PC 側エンドポイントが起動しているか、スマートフォンから到達できるか、JSON に `url` と `token` があるか |
| LiveKit に接続できない | token の有効性、LiveKit の URL、TLS、DNS、ファイアウォール、UDP／TURN の設定 |
| マイクを使えない | Android 設定でマイク権限が許可されているか、他アプリが占有していないか |
| バックグラウンドで停止する | 端末の省電力設定が常駐サービスを制限していないか |
| APK を更新できない | インストール済み APK と新しい APK が異なる署名鍵で署名されていないか |
